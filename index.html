Rencana bulanan · opsional

Anggaran / aktual / gap

Kosong = belum dianggarkan; 0 = target nol. Gap = budget − aktual; negatif berarti terlampaui. Semua kategori pengeluaran boleh dipakai atau tidak.

Arus kas aktual bulan ini minus. Buat improvement untuk simulasi menekan anggaran, bukan mengubah pengeluaran yang sudah terjadi.

Kelola kategori pengeluaran

Centang untuk pilihan transaksi baru. Menonaktifkan / mengganti nama tidak mengubah catatan lama. Andreas: dukungan adik; Ortu: bantuan tunai orang tua; UKT: kuliah adik. Semuanya pengeluaran opsional, bukan tabungan.

Improvement · simulasi saja

Satu simulasi tersimpan per bulan. Tidak mengganti anggaran aktif atau transaksi. Bahkan untuk bulan lampau, proyeksi ini tidak mengubah sisa aktual. Baseline memakai budget; jika kosong memakai aktual (diberi label).
